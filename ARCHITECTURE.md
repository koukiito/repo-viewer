## MVVM Pattern

The project follows the MVVM pattern, which separates the application logic into three main components:

- **Model**: Represents the data and business logic of the application. Models are located in the `lib/data/model/` directory.
- **View**: Represents the UI of the application. Views are located in the `lib/ui/` directory.
- **ViewModel**: Acts as a bridge between the Model and the View. ViewModels are responsible for handling user input, updating the Model, and updating the View. ViewModels are located in the respective feature directories under `lib/ui/`.
